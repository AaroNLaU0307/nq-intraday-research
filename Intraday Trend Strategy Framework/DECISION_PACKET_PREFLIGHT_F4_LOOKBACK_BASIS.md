# DECISION PACKET — F4 前 60 交易日的参照日集合

状态：PENDING（SA-3 提出；推荐栏留空给 main agent）
来源：M4-T4 / SA-3 S0_INPUT_PREFLIGHT，input_commit `d09ce4e`

## 1. 问题

F4 `rvol_open30 = Vol(09:30–10:00) ÷ 前 60 交易日同窗中位数`（预注册行 56）。
冻结文本唯一确定了**回看长度**（60 个交易日）与**窗口**（09:30–10:00），
但**未确定"交易日"指哪一个日集合**：

- 是否包含**已排期半日市**？（半日市的 09:30–10:00 是完整正常的早盘窗口，
  被剔除的是下午时段）
- 是否包含**未通过资格漏斗**的日（如 >10% 缺失日、ADR14 warm-up 日）？
- 是否要求参照日自身的 09:30–10:00 窗口**完整 30 根**？

## 2. 冻结章节与依据

- 行 56：F4 定义（"前 60 交易日同窗中位数"）。
- 行 44：剔除日三类（半日市因**下午**不交易而被剔除，非早盘缺陷）。
- 行 45：NA 政策（算不出记 NA，日保留，每表报 NA 数）。

## 3. 事实（本次 preflight 实测）

- 本次实现采用的规则（已在报告与 json 中显式披露，未静默选择）：
  **前 60 个"观测到 RTH 且 09:30–10:00 窗口完整 30 根"的交易日，
  严格早于当日，包含已排期半日市**。
- 该规则下 F4：可构建 **2823** 天 / NA **59** 天，NA 原因全部为
  `f4_lookback_warmup`（样本最初期缺 60 天回看），无其他原因。
- 参考量级：合格日 L3 = 2882；ADR14 warm-up 仅 14 天，故 F4 的 warm-up
  比 ADR14 多约 45 天，这是两个 warm-up 长度不同的自然结果，不是缺陷。

## 4. Option A（维持本次实现）

参照集 = 观测到 RTH 且早盘窗口完整的交易日（含半日市）。
理由：半日市早盘窗口与常规日同质；要求窗口完整可避免用残缺窗口的
成交量做中位数基准。

## 5. Option B（仅用通过资格漏斗的日作参照）

参照集 = 结构合格日（排除半日市、>10% 缺失日）。
理由：与特征表的样本口径一致，参照集与被归一化的日集同源。

## 6. 影响方向

- **不改变样本日数**：两案都不删日；差异只在 F4 的 NA 计数与分母取值。
- NA 计数差异很小（仅影响样本最初 60 个交易日的边界，量级 ≤ 数天）。
- 分母（中位数）本身会因参照集不同而略有差异，但该数值**不在本报告输出
  范围内**，preflight 未输出任何 F4 数值。
- 两案均不影响 Primary、成本、标签与判决。

## 7. main agent 推荐

main agent 推荐 **Option A（维持本次实现：前 60 个观测到 RTH 且早盘
窗口完整 30 根的交易日，含半日市）**（仅供 Aaron/ChatGPT 参考）：
半日市的 09:30-10:00 与常规日同质（被剔除的是下午）；"窗口完整"要求
保证中位数分母可比；B 案会把下游资格漏斗语义耦合进滚动统计的参照集，
使 F4 的取值依赖与成交量无关的资格规则（如 ADR warm-up），属不必要的
循环依赖。A 案规则已在报告与 json 显式披露，无静默选择。
